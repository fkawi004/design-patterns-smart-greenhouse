# Course phase order

This repository grows one phase at a time. Each phase keeps the same three-tier foundation and adds behaviour without restructuring it.

1. Phase 1 — empty-but-running skeleton (no design pattern)
2. Phase 2 — Factory Method and sensor devices (completed)
3. Phase 3 — Abstract Factory and coherent device families (completed)
4. Phase 4 — Builder and location configuration (completed)
5. Phases 5–12 — additional course patterns and greenhouse capabilities

Phase-specific requirements, implementation notes, and answers belong under this directory.
